Language guide

Short examples clarify what INPUT and IF actually do.

INPUT = read and store

INPUT FRONT_IS_CLEAR INTO pathOpen asks the robot sensor for a value and stores that value in pathOpen.

INPUT FRONT_IS_CLEAR INTO pathOpen
OUTPUT pathOpen

Important: moving or turning does not automatically update pathOpen. Use INPUT again to read the new situation.

IF = choose one path 
INPUT FRONT_IS_CLEAR INTO pathOpen
IF pathOpen THEN
  MOVE
ELSE
  TURN RIGHT
END IF

If pathOpen is TRUE, the robot moves. If it is FALSE, the robot turns right. Only one branch runs.

Task sensor example 
INPUT CURRENT_TASK INTO task
IF task = "CLEAN" THEN
  CLEAN
END IF

The condition is useful because the action happens only when the current tile asks for it.

Loops 
REPEAT 4 TIMES
  MOVE
END REPEAT
WHILE FRONT_IS_CLEAR DO
  MOVE
END WHILE

INCREASE steps BY 1
OUTPUT steps
